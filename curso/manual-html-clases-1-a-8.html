CLASE 1 · HTML DESDE CERO

Fundamentos y estructura minima

Objetivo: Comprender que es HTML y construir el esqueleto basico de una pagina.

Contenido de la clase

  • Declaración <!DOCTYPE html> y documento HTML5
  • Elemento raíz <html> y atributo lang
  • Metadatos dentro de <head>
  • Contenido visible dentro de <body>
  • Títulos con <h1> y párrafos con <p>

Explicacion y buenas practicas

  • HTML describe la estructura y el significado del contenido; no es un lenguaje de programación.
  • <!DOCTYPE html> informa al navegador que se usa HTML5.
  • lang="es" ayuda a lectores de pantalla, buscadores y traductores.
  • UTF-8 permite representar correctamente acentos, eñes y otros caracteres.
  • viewport adapta el ancho de la página a celulares.
  • Debe existir un título de pestaña claro mediante <title>.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jhakorn - Clase 01</title>
</head>
<body>
    <h1>Bienvenido a Jhakorn</h1>
    <p>Servicio tecnico de computadoras e impresoras.</p>
</body>
</html>

CLASE 2 · HTML DESDE CERO

Textos, jerarquia y comentarios

Objetivo: Organizar contenido escrito con titulos, parrafos, enfasis y saltos de linea.

Contenido de la clase

  • Jerarquía de encabezados <h1>, <h2> y <h3>
  • Comentarios HTML <!-- ... -->
  • Énfasis semántico con <strong> y <em>
  • Salto de línea con <br>

Explicacion y buenas practicas

  • Use un solo <h1> que describa el tema principal y continúe la jerarquía sin elegir niveles solo por su tamaño.
  • Los comentarios sirven para documentar el código y no aparecen en la página.
  • <strong> indica importancia y <em> énfasis; ambos aportan significado además de su apariencia.
  • <br> es apropiado para una ruptura necesaria dentro de un texto, no para crear espacio visual.
  • La presentación visual se controlará después con CSS.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jhakorn - Clase 02</title>
</head>
<body>
    <!-- Titulo principal -->
    <h1>Jhakorn</h1>

    <!-- Presentacion -->
    <h2>Servicio tecnico</h2>
    <p>
        Brindamos soporte tecnico para computadoras e impresoras.
    </p>

    <!-- Servicios -->
    <h2>Nuestros servicios</h2>

    <h3>Computadoras</h3>
    <p>
        Realizamos mantenimiento preventivo, diagnostico
        y configuracion de programas.
    </p>

    <h3>Impresoras</h3>
    <p>
        Realizamos mantenimiento, limpieza y diagnostico
        de problemas de impresion.
    </p>

    <!-- Informacion de contacto -->
    <h2>Contacto</h2>
    <p>
        <strong>Atencion:</strong> lunes a viernes.<br>
        <em>Servicio personalizado para cada cliente.</em>
    </p>
</body>
</html>

CLASE 3 · HTML DESDE CERO

Enlaces y botones

Objetivo: Conectar paginas, recursos externos y acciones de contacto.

Contenido de la clase

  • Enlace interno con ruta relativa
  • Enlace externo y nueva pestaña
  • Protocolos mailto: y tel:
  • Botón <button>

Explicacion y buenas practicas

  • <a> crea un hipervínculo y href indica el destino.
  • Una ruta como clase-02.html busca el archivo en la misma carpeta.
  • target="_blank" abre otra pestaña; rel="noopener noreferrer" protege la página de origen.
  • mailto: abre la aplicación de correo y tel: permite iniciar una llamada en dispositivos compatibles.
  • Un botón no navega por sí solo: necesita un formulario o JavaScript para ejecutar una acción.
  • El texto del enlace debe describir claramente su destino.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jhakorn - Clase 03</title>
</head>
<body>
    <!-- Titulo principal -->
    <h1>Enlaces y botones</h1>

    <!-- Enlace interno -->
    <h2>Navegacion entre paginas</h2>
    <p>
        <a href="clase-02.html">Volver a la Clase 02</a>
    </p>

    <!-- Enlace externo -->
    <h2>Pagina externa</h2>
    <p>
        <a href="https://www.google.com" target="_blank" rel="noopener noreferrer">
            Abrir Google en otra pestana
        </a>
    </p>

    <!-- Enlace de correo -->
    <h2>Correo electronico</h2>
    <p>
        <a href="mailto:contacto@jhakorn.com">Enviar un correo</a>
    </p>

    <!-- Enlace de telefono -->
    <h2>Telefono</h2>
    <p>
        <a href="tel:+59170000000">Llamar a Jhakorn</a>
    </p>

    <!-- Boton sin accion por ahora -->
    <h2>Boton HTML</h2>
    <button type="button">Solicitar servicio</button>
</body>
</html>

CLASE 4 · HTML DESDE CERO

Imagenes accesibles

Objetivo: Insertar imagenes locales con dimensiones, texto alternativo y pie descriptivo.

Contenido de la clase

  • Elemento <img> y atributo src
  • Texto alternativo alt
  • Dimensiones width y height
  • Agrupación con <figure> y <figcaption>

Explicacion y buenas practicas

  • <img> es un elemento vacío: no necesita etiqueta de cierre.
  • src contiene la ruta del archivo; aquí es una imagen SVG local.
  • alt comunica el contenido o función a quien no puede ver la imagen.
  • width y height reservan espacio y reducen saltos visuales mientras carga.
  • <figure> agrupa contenido autónomo y <figcaption> ofrece una descripción visible.
  • Una imagen decorativa debe usar alt=""; una imagen informativa necesita un texto útil.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jhakorn - Clase 04</title>
</head>
<body>
    <h1>Imagenes en HTML</h1>

    <!-- Imagen local con descripcion alternativa -->
    <img
        src="imagen-jhakorn.svg"
        alt="Computadora que representa el servicio tecnico de Jhakorn"
        width="800"
        height="450"
    >

    <!-- Imagen acompañada por una descripcion visible -->
    <figure>
        <img
            src="imagen-jhakorn.svg"
            alt="Ilustracion de una computadora con el simbolo de Jhakorn"
            width="400"
            height="225"
        >
        <figcaption>Ejemplo de imagen para la pagina de Jhakorn.</figcaption>
    </figure>

    <p>
        <a href="clase-03.html">Volver a la Clase 03</a>
    </p>
</body>
</html>

CLASE 5 · HTML DESDE CERO

Listas y tablas

Objetivo: Representar colecciones, secuencias, definiciones y datos tabulares.

Contenido de la clase

  • Lista sin orden <ul>
  • Lista ordenada <ol>
  • Lista descriptiva <dl>
  • Tabla con caption, thead y tbody
  • Filas <tr>, encabezados <th> y celdas <td>

Explicacion y buenas practicas

  • <ul> sirve cuando el orden no cambia el significado; <ol>, cuando la secuencia importa.
  • <dl> relaciona términos <dt> con descripciones <dd>.
  • Las tablas son para datos relacionados, no para diseñar la distribución de la página.
  • <caption> explica el propósito de la tabla.
  • scope="col" vincula cada encabezado con su columna y mejora la accesibilidad.
  • <thead> y <tbody> hacen explícita la estructura de los datos.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jhakorn - Clase 05</title>
</head>
<body>
    <h1>Listas y tablas</h1>

    <!-- Lista sin orden -->
    <h2>Servicios disponibles</h2>
    <ul>
        <li>Mantenimiento de computadoras</li>
        <li>Soporte para impresoras</li>
        <li>Instalacion de programas</li>
    </ul>

    <!-- Lista ordenada -->
    <h2>Proceso de atencion</h2>
    <ol>
        <li>Recibir el equipo</li>
        <li>Realizar el diagnostico</li>
        <li>Informar el resultado</li>
        <li>Realizar el servicio autorizado</li>
    </ol>

    <!-- Lista de descripcion -->
    <h2>Terminos frecuentes</h2>
    <dl>
        <dt>Diagnostico</dt>
        <dd>Revision para identificar la causa de un problema.</dd>

        <dt>Mantenimiento preventivo</dt>
        <dd>Servicio realizado para prevenir posibles fallas.</dd>
    </dl>

    <!-- Tabla de servicios -->
    <h2>Tabla de servicios</h2>
    <table>
        <caption>Servicios tecnicos de ejemplo</caption>
        <thead>
            <tr>
                <th scope="col">Servicio</th>
                <th scope="col">Tipo de equipo</th>
                <th scope="col">Modalidad</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>Mantenimiento</td>
                <td>Computadora</td>
                <td>Presencial</td>
            </tr>
            <tr>
                <td>Limpieza</td>
                <td>Impresora</td>
                <td>Presencial</td>
            </tr>
            <tr>
                <td>Configuracion</td>

CLASE 6 · HTML DESDE CERO

Formularios

Objetivo: Capturar datos mediante controles accesibles y validacion basica del navegador.

Contenido de la clase

  • Formulario <form>, action y method
  • Etiquetas <label> e inputs
  • Tipos text, email, tel, radio y checkbox
  • Lista <select> y <option>
  • Área <textarea>
  • Agrupación <fieldset> y <legend>
  • Botones submit y reset
  • Validación required

Explicacion y buenas practicas

  • Cada control debe tener name para que su valor sea enviado.
  • El for de <label> debe coincidir con el id del control.
  • El tipo email activa validación básica y teclados apropiados en móviles.
  • Los radios con el mismo name forman un grupo de elección única.
  • required impide el envío vacío, pero un sistema real también valida en el servidor.
  • method="get" coloca los datos en la URL y no es adecuado para información sensible.
  • action vacío envía a la misma página; esta práctica no almacena los datos.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jhakorn - Clase 06</title>
</head>
<body>
    <h1>Formulario de solicitud</h1>

    <!-- Formulario de practica sin conexion a un servidor -->
    <form action="" method="get">
        <p>
            <label for="nombre">Nombre:</label><br>
            <input type="text" id="nombre" name="nombre" required>
        </p>

        <p>
            <label for="correo">Correo:</label><br>
            <input type="email" id="correo" name="correo" required>
        </p>

        <p>
            <label for="telefono">Telefono:</label><br>
            <input type="tel" id="telefono" name="telefono">
        </p>

        <p>
            <label for="servicio">Servicio:</label><br>
            <select id="servicio" name="servicio" required>
                <option value="">Selecciona una opcion</option>
                <option value="computadora">Soporte para computadora</option>
                <option value="impresora">Soporte para impresora</option>
                <option value="programas">Instalacion de programas</option>
            </select>
        </p>

        <fieldset>
            <legend>Modalidad preferida</legend>

            <input type="radio" id="presencial" name="modalidad" value="presencial" required>
            <label for="presencial">Presencial</label><br>

            <input type="radio" id="remota" name="modalidad" value="remota">
            <label for="remota">Remota</label>
        </fieldset>

        <p>
            <label for="mensaje">Describe el problema:</label><br>
            <textarea id="mensaje" name="mensaje" rows="5" cols="40" required></textarea>
        </p>

        <p>
            <input type="checkbox" id="acepta" name="acepta" required>
            <label for="acepta">Acepto enviar esta solicitud de practica</label>
        </p>

        <button type="submit">Enviar solicitud</button>
        <button type="reset">Limpiar formulario</button>
    </form>

    <p>
        <a href="clase-05.html">Volver a la Clase 05</a>
    </p>
</body>
</html>

CLASE 7 · HTML DESDE CERO

HTML semantico y accesibilidad

Objetivo: Dividir una pagina en regiones con significado para usuarios, buscadores y tecnologias de asistencia.

Contenido de la clase

  • Regiones header, nav, main y footer
  • Secciones <section> y contenidos <article>
  • Contenido complementario <aside>
  • Navegación interna con identificadores
  • Descripción meta y atributos ARIA

Explicacion y buenas practicas

  • <header> presenta la página; <nav> agrupa la navegación principal.
  • <main> contiene el contenido principal y normalmente aparece una sola vez.
  • <section> agrupa un tema; suele incluir un encabezado.
  • <article> identifica una unidad reutilizable o independiente.
  • <aside> contiene información relacionada pero secundaria.
  • <footer> reúne cierre, autoría o enlaces finales.
  • href="#servicios" lleva al elemento id="servicios".
  • aria-label distingue una región cuando hace falta un nombre accesible.

Codigo completo

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Servicios de soporte tecnico para computadoras e impresoras.">
    <title>Jhakorn - Clase 07</title>
</head>
<body>
    <!-- Encabezado principal -->
    <header>
        <h1>Jhakorn</h1>
        <p>Soluciones para computadoras e impresoras</p>

        <!-- Menu de navegacion -->
        <nav aria-label="Navegacion principal">
            <ul>
                <li><a href="#inicio">Inicio</a></li>
                <li><a href="#servicios">Servicios</a></li>
                <li><a href="#consejos">Consejos</a></li>
                <li><a href="#contacto">Contacto</a></li>
            </ul>
        </nav>
    </header>

    <!-- Contenido principal unico de la pagina -->
    <main>
        <section id="inicio">
            <h2>Bienvenido</h2>
            <p>
                Brindamos soporte tecnico para hogares y pequenos negocios.
            </p>
        </section>

        <section id="servicios">
            <h2>Servicios</h2>

            <article>
                <h3>Soporte para computadoras</h3>
                <p>
                    Realizamos diagnostico, mantenimiento y configuracion.
                </p>
            </article>

            <article>
                <h3>Soporte para impresoras</h3>
                <p>
                    Revisamos problemas de impresion, conexion y limpieza.
                </p>
            </article>
        </section>

        <section id="consejos">
            <h2>Consejos tecnicos</h2>

            <article>
                <h3>Realiza copias de seguridad</h3>
                <p>
                    Guarda tus archivos importantes en mas de una ubicacion.
                </p>
            </article>
        </section>

        <!-- Informacion relacionada pero complementaria -->
        <aside>
            <h2>Recomendacion</h2>
            <p>
                No instales programas desde sitios que no sean confiables.
            </p>
        </aside>

        <section id="contacto">
            <h2>Contacto</h2>
            <p>
                <a href="mailto:contacto@jhakorn.com">Enviar un correo</a>
            </p>
        </section>
    </main>

    <!-- Pie de pagina -->
    <footer>
        <p>Jhakorn - Servicio tecnico</p>
        <p><a href="clase-06.html">Volver a la Clase 06</a></p>
    </footer>
</body>
</html>

CLASE 8 · HTML DESDE CERO

Proyecto integrador: pagina completa

Objetivo: Combinar en una sola pagina todos los componentes estudiados en las clases anteriores.

Contenido de la clase

  • Estructura semántica completa
  • Menú de navegación interno
  • Presentación con imagen accesible
  • Servicios mediante artículos y listas
  • Proceso con lista y tabla
  • Consejo complementario
  • Formulario de contacto
  • Pie y enlaces de retorno

Explicacion y buenas practicas

  • La página reúne contenido, navegación y captura de datos siguiendo una jerarquía coherente.
  • aria-labelledby conecta la sección con el título que la nombra.
  • Los id deben ser únicos y pueden servir como destinos de navegación y asociaciones accesibles.
  • La tabla resume modalidades; la lista explica el proceso paso a paso.
  • El formulario aún es demostrativo: para funcionar requiere un servidor o servicio que procese el envío.
  • El resultado es HTML puro; CSS puede añadirse después sin cambiar su estructura semántica.
