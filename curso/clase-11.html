Modelo de caja CSS

Contenido, relleno, borde y margen

Partes de una caja

Este texto es el contenido.

  • Contenido: texto o elementos internos.
  • Padding: espacio entre contenido y borde.
  • Border: linea alrededor del padding.
  • Margin: espacio exterior de la caja.

Comparacion de box-sizing

content-box

El padding y el borde se suman al ancho.

border-box

El padding y el borde se incluyen en el ancho.
